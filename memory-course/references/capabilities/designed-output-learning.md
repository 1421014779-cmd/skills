## I — 方法论骨架 (Interpretation)

学任何东西，若只有输入——抄笔记、画思维导图、认认真真格式化——第二天一问往往全忘。讲者把这类没有「设计输出」的动作称为废品或至多是准备动作：大脑需要经过创造、回忆、应用，记忆强度才会上来。

更早一讲给出一个可背的「万能学习模型」骨架：第一步当间谍——先搞清楚「匪首在哪里」，也就是考什么、要输出什么；第二步短输入——一次不要灌太多，灌多了会很快忘掉；停下来，马上按目标做输出。若目标是认知理解，就提问并尝试用自己的话回答。

10/15-2 把「学习最重要的动作」收成四个字：设计输出。因为每个人学的材料不同，输出也要按材料设计，从而驱动创造、回忆、应用。左边应形成一个知识框架（不一定整本背下来）：收集问题、搞懂核心概念、用真题倒推学习动作。右边通过不同输出获得不同记忆强度，首先是把「不懂」变成「懂」（方向和方法要对，例如复习用残缺刺激而不是白板默写）。

与之配套的选材原则：10/9 要求只背「能指导后续行动的规则」；10/15 进一步说不要背杂七杂八，把高效规则练到接近「九九乘法表」那样可提取（10/15 文稿后半截断，不补细则）。

## A1 — 应用示例 (Application Example)

### 示例 1: 只做笔记和导图、没有输出
- **类型与来源**: 原书例题 / 10/15-2 00:46:14
- **问题/输入**: 把注会或建造师题目压缩、抄笔记、做成漂亮导图
- **方法论的使用**: 指出这只有输入和整理，没有设计输出；按讲者课堂断言，第二天提问会大面积遗忘。
- **结论**: 整理可以是准备，但不能代替输出。
- **结果**: 讲者称为「做了 20 年实验」并提到一名学员考上北大；具体实验数据与成绩单本讲未见。

### 示例 2: 当间谍之后短输入、立即默写
- **类型与来源**: 课堂演示 / 10/13 01:40 附近
- **问题/输入**: 一段关于亲权、物权等关系的材料
- **方法论的使用**: 先对准要考的点，短输入后立刻暂停并输出，围绕不同需求建立不同强度。
- **结论**: 「知道匪首在哪里 + 短输入 + 马上输出」比一次灌完再幻想以后会记住更有效。
- **结果**: 讲者当场表示能默写；无独立测试。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 学了一整天，笔记很工整，一提问就空。
2. 不知道从何下手：材料很多，既想全看完又来不及输出。
3. 想把「学习靠输出、复习靠残缺刺激」落实成一套动作，而不是继续增加输入。

### 语言信号

- 「我抄了笔记、画了导图，为什么还是忘」
- 「学习最重要的动作是什么 / 设计输出」
- 「当间谍、短输入、马上输出」
- 「这些东西要不要全部背下来？」

### 与相邻能力的区分

- 与 `cued-recall-review` 的区别: 本卡是学习阶段的输出设计；复习阶段的短刺激提取走复习卡。
- 与 `mindmap-sanpei-audit` 的区别: 本卡从学习模型出发，导图只是「没有输出的输入」的一种；三配是导图专项诊断。
- 与 `three-dimension-conversion` 的区别: 转化是编码技术；本卡决定要不要编码、编码后用什么输出去检验。

## E — 可执行步骤 (Execution)

**必需输入**: 学习目标（考试/应用/理解）；材料范围。缺目标时先当「间谍」问清要能交出什么。
**交付物与完成标准**: 一份学习动作清单：目标输出是什么、一次输入多大、立即做什么输出、哪些规则值得背到可提取、哪些只作框架。完成标准：清单里必须有「停下来输出」的动作，不能只有阅读和做笔记。

1. **当间谍**  
   写明最终要能回答或完成的具体任务（题型、应用情境）。完成标准：能指出「匪首」——被考或被用的点。
2. **短输入**  
   只切一小段。明确禁止「先把整章看完再算」。
3. **立即按目标设计输出**  
   理解类：提问并用自己的话回答；记忆类：用残缺刺激提取或做小块编码后立刻回述；应用类：做一道对应题。完成标准：每段输入都对应至少一种输出。
4. **搭知识框架，而不是先背整本书**  
   收集问题、核心概念，用真题或真实任务倒推还缺什么。只把能指导后续行动的规则选入「值得背到可提取」的名单。
5. **把复习交给残缺刺激**  
   编码完成后的定期提取，调用 `cued-recall-review`。
6. **判停**  
   用户其实需要的是「这组考点怎么编码」，转到转化/定位/序列桩。只是导图诊断，转到 `mindmap-sanpei-audit`。

## B — 边界 (Boundary)

- 不要把「设计输出」理解成禁止记笔记或画导图；它们最多是准备动作。
- 「快 100 倍」「20 年实验」「学员上北大」是讲者陈述，不能当已核实的效果保证。
- 10/13 提到还有「更高端」的学习模型要到下一讲；本卡已把 10/15-2 的「设计输出」大模型合并进来，但更细的「三种记忆强度」后半在摘录中未完全展开，执行时只使用已讲清的部分（先解决不懂变懂、方向方法要对）。
- 选材原则「只背指导行动的规则」来自 10/9 与 10/15；10/15 文稿在后半截断，不补造未出现的细则。
