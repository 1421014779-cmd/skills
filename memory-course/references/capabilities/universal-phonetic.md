## I — 方法论骨架 (Interpretation)

万能谐音建立在汉语「单音单字」上：一个字一个音，几乎任何读音都能转成影像。英语以多音节词为基本单位，很难为整词找到既近音又具象的匹配；本方法不要拿去当英语单词的整词谐音公式。

操作骨架在 10/16 已给本质：单音单字先出图，再动态发散，组合成逻辑最好的画面。10/22 把训练补全为：把目标拆成单音；每个音沿名、动、状（含事物外在形态）发散；再组合成**熟悉的关系**，而不是一堆互不相干的图像。课堂训练用常见约 390 个音做「名动状穷举、不重不漏、均匀覆盖」。**宁老师课上的原表本包没有随附，不要假装课上原表已内置。** 另附一份 fish 自做的练习用音表（`references/392-yinbiao.md`），只是可选库存，不强制先查；需要查阅或训练时可用，没有合适的词仍按同一规则自列。

提速技巧：构思时优先想状态和动作，最后再想名词。状态和动作种类较少，用「多的名词去迎合少的状态/动作」，更容易配出熟悉关系。熟悉关系有两个目的：便于迁移，也记得更牢。

谐音是三维转化里的一维，不是独家通路。10/26–27 警告：信息本身有内在逻辑时，只靠谐音会把逻辑丢掉；应先立类比/逻辑框架，再用谐音修饰边角。出图后仍要用回忆导向和辨识度检查。

## A1 — 应用示例 (Application Example)

### 示例 1: 单音组合要直接，避免绕远
- **类型与来源**: 课堂改作业 / 10/22 00:30 后
- **问题/输入**: 学员把某组音编成「鸭血可以食用，在厨房烹饪」，路径偏长
- **方法论的使用**: 改成更直接的画面（如「眼睛里的血丝很粗」），状态加状态也可以出图，但要一眼能抓住。
- **结论**: 能出熟悉、短而可辨的关系，优于编一个很长的故事。
- **结果**: 课堂当场改图；无延迟对照。

### 示例 2: 优先状态和动作再配名词
- **类型与来源**: 原书原则 / 10/22 00:39:13–00:41:48
- **问题/输入**: 练习时先堆名词，配不出熟悉关系
- **方法论的使用**: 先出较少的状态/动作，再用较多的名词去迎合，配熟悉关系。
- **结论**: 「多去迎合少」比「少去迎合多」更容易配上。
- **结果**: 作为训练口诀讲授。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要把抽象词、人名、专名或没有现成逻辑的音节转成可想象的图。
2. 已经知道「谐音出图」，但经常编不出来，或编出的关系很陌生、不便迁移。
3. 类比或逻辑框架已经有了，需要用谐音补边角细节。

### 语言信号

- 「万能谐音 / 单音单字出图 / 名动状」
- 「这个音怎么出图」
- 「392 音表 / 不重不漏穷举」

### 与相邻能力的区分

- 与 `three-dimension-conversion` 的区别: 那张卡是三维总框架；本卡是谐音维的完整训练与组合规则。
- 与 `analogy-memory` 的区别: 有内在逻辑时先类比框架，谐音只修饰；不要用本卡把逻辑拆光。
- 与 `recall-orientation-revise` 的区别: 本卡负责出图；导向不准或辨识度低时转到那张卡。

## E — 可执行步骤 (Execution)

**必需输入**: 待转化的字、词或音组。若用户要「整词谐英语多音节」，先说明本方法依赖单音单字优势，不要硬套。
**交付物与完成标准**: 每个音有名/动/状候选，并给出一组熟悉关系的画面。完成标准：画面可想象、关系说得通，且能指向目标音/字。

1. **拆成单音**  
   按字/音节切开，不要整句只找一个近音词。
2. **各音沿名、动、状发散**  
   状包括外在形态。先状态和动作，再配名词。
3. **组合成熟悉关系**  
   优先生活中见过的关系，服务迁移和牢固度。宁短不宁长。
4. **需要训练基本功时**  
   对常用音做名动状穷举，求不重不漏、均匀覆盖。可选用练习用附加表 `references/392-yinbiao.md`，也可自列；不要虚构课上原表的内容，也不把查附加表写成必经步骤。
5. **交下游检查**  
   导向与辨识度走 `encoding-six-principles` / `recall-orientation-revise`；有内在逻辑的材料先问是否应走 `analogy-memory`。
6. **判停**  
   用户要的是序列怎么排、位置怎么放，转到序列桩或内定位/交集。

## B — 边界 (Boundary)

- 10/16 已讲本质并提前开练，以 10/22 为主体；不要把课上的 392 音表写成随包附件。`references/392-yinbiao.md` 是后来附上的练习用表，与课上原表不是同一份。
- 不把「几乎 100%」写成对任意语言、任意方言的保证。
- 同音字可用，但组合要能区分；不要用少见、难以辨认的画面充数。
- 谐音不是默认第一选择：能用逻辑或类比框架时，不要先把信息拆成互不相干的音。
