## I — 方法论骨架 (Interpretation)

一条看起来「做了定位」的编码，常常会忘，是因为抓手其实不是位置，或这个位置在心里站不稳。

检验时按四条原则看（由本讲分述归纳，不另增第五条）：

1. **小而准，且与目标词强相关**：不能宽到「医院」这种大类；脑海中应能落到一个很小的点，并容易由抽象词唤起。
2. **心理印象固定**：不能今天在这、明天在那。实地改建或拆除不要紧，只要印象还在；但印象本身漂移就不行。
3. **最好有强情感事件支撑**：不是必须，但有则更稳、更快。
4. **位置可以就是转化主体本身**：例如「缺了一块的石阶」直接对应「缺陷」，不必再外挂一个无关房间。

另外两条支撑规则：定位的主角是位置，不是位置上临时出现的物象；优先使用亲身经历的位置，必要时通过与位置的身体互动来增加库存。实际学习中虚拟宫殿用得更多，虚拟位置同样要印象固定、逻辑成立。

## A1 — 应用示例 (Application Example)

### 示例 1: 「新鲜」——脸盆里的鱼 vs 保鲜膜
- **类型与来源**: 原书对照演示 / 00:16:52–00:19:31
- **问题/输入**: 把「新鲜」放到「家里脸盆里一条刚买的鱼」
- **方法论的使用**: 脸盆是物象，不是定位；用途随机（洗菜、洗鱼、洗脚），对「新鲜」没有强烈而稳定的回忆属性。即使补上上下左右，仍不是好定位。改到厨房里保鲜膜的固定位置：职能就是让食物保鲜，并交代冰箱、油烟机、玻璃门等上下左右。
- **结论**: 不合格的是「临时物象 + 随机用途」；合格的是「职能稳定、印象固定的小位置」。
- **结果**: 作为教材对照，原书未给遗忘率数据。

### 示例 2: 宽泛位置、会移动的位置、以及「位置即转化主体」
- **类型与来源**: 原书例题与亲历 / 00:19:31–00:32:23
- **问题/输入**: 「医院」当位置；家里哑铃/档案被挪来挪去；「缺陷」要找位置
- **方法论的使用**: 医院太宽；哑铃今天在这明天在那会乱；别墅台阶上缺了一块的石头本身就是「缺陷」的位置。
- **结论**: 过宽、会漂移都不合格；能让位置成为信息的转化主体则更省。
- **结果**: 课堂说明，无量化跟踪。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 已经做了定位或宫殿，但复习或考试时经常找错地方、或和别的条目串台。
2. 请人检查「我这条定位为什么不稳」。
3. 纠结生活中的地点拆了、搬家了，定位是否作废。

### 语言信号 (用户的话里出现这些就应激活)

- 「我的定位总是忘 / 总是混淆 / 不稳定」
- 「这算不算一个好的记忆位置？」
- 「why is my memory palace locus unstable / too vague」
- 「那个地方已经拆了，定位还能用吗？」

### 与相邻能力的区分

- 与 `internal-loci-encoding` 的区别: 本卡假设已有一条编码，做诊断和返工；不是从零开始设计。
- 与 `ai-palace-scene-design` 的区别: 出图逻辑和差异化归出图卡；本卡管「这个位置在心理上站不站得住」。
- 与 `intersection-loci` 的区别: 同义项撞车优先走交集定位；本卡处理单条位置的稳定性。
- 与 `sequential-pegs` 的区别: 序列桩八原则管「一组桩」的聚焦、跳跃、包含关系等；本卡管已经做成的单条定位是否站得住。两条可对照使用。

## E — 可执行步骤 (Execution)

**必需输入**: 已有编码方案（位置、联想、目标信息）；使用者觉得失败的症状（可选）。没有已有方案时，先询问或转 `internal-loci-encoding`。
**交付物与完成标准**: 四原则核对表（通过/失败 + 一句理由）+ 改写后的位置方案（若失败）。完成标准：改写后的位置能指出「主角是哪个小位置、为何与信息相关、印象为何固定」。

1. **确认主角是不是位置**  
   若抓手只是可移动、多用的物件（如脸盆），判定为物象，不是定位。
2. **逐条套用四原则**  
   检查：是否小而准且强相关；心理印象是否固定；有无情感支撑（加分，不是否决项）；位置是否可以就是转化主体。完成标准：每条有判定，不把「优先亲身经历」写成第五条否决规则。
3. **处理实地变迁**  
   若用户担心地点拆了：只要心理印象还在，不必作废；若印象已经漂到 A/B/C 多处，必须重做。
4. **给出改写**  
   优先改用亲身经历、职能稳定、上下左右清楚的小位置；虚拟位置则要求逻辑上也会「一直在那里」。可选建议：通过与位置互动来加固或扩充库存。
5. **判停**  
   失败主因是同义撞车或画面长得太像，转到 `intersection-loci` 或 `ai-palace-scene-design`。材料根本还没有编码，转回 `internal-loci-encoding`。

## B — 边界 (Boundary)

- 不要用来从零编码一篇新材料。
- 不要因为实地拆迁就宣布定位无效，也不要反过来保证「印象永远不会丢内容」（讲者自己有位置在、内容忘了的例子）。
- 不要强迫学习者使用创伤性情感记忆。
- 亲身位置库存有限，尤其常待在家里的人；实际学习更常走 AI 虚拟宫殿，本卡不能要求「必须是现实地点」。
- 四原则是课堂分述的归纳，原文没有写成一张正式检查表；执行时不得添加原书没有的否决项。
