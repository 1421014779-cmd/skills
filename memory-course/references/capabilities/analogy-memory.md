## I — 方法论骨架 (Interpretation)

当材料内部有逻辑时，不要只用万能谐音另起一套完全新的图像——那样会把内在逻辑丢掉。类比的做法是：先抓住这件事的逻辑框架（尤其是行为），做成一个可想象的类比，再对框架盖不住的细节用谐音修饰。

课堂步骤：①忽略逻辑主体（不要死盯原领域的抽象主语）；②找行为词，或把几个词合成一组，做成类比框架；③万能谐音修饰边角。追求近似，不要追求与原领域「一模一样」的案例；硬要在本领域找原意类比，会卡死。前提是信息本身有逻辑性；没有逻辑，就不要强行类比。

类比的命脉是行为。能记住的类比尽量带动作画面；只有抽象相似、没有图，回忆导向会和别的相似逻辑搅在一起。讲者把类比的功能说成三种：开悟、识人、记忆。本卡只执行「记忆」这条；开悟/识人的例子可作理解辅助，不另开能力。

和交集一样，核心是「能不硬搞就不硬搞」：能借用材料自带的逻辑整体，就不要把每个字重新谐音。

## A1 — 应用示例 (Application Example)

### 示例 1: 框架先站住，细节用谐音补
- **类型与来源**: 课堂原则 / 10/26–27（如「苹果上有蚂蚁」一类修饰细节）
- **问题/输入**: 只记住了框架，细节总丢
- **方法论的使用**: 先立类比框架，再用谐音把细节钉在画面上（修饰，而不是重起一套谐音故事）。
- **结论**: 框架负责整体逻辑，谐音负责边角。
- **结果**: 课堂示范；不是受控实验。

### 示例 2: 不要逼自己找本领域原意案例
- **类型与来源**: 原书警告 / 10/26
- **问题/输入**: 用户要求「必须在该专业里找一个一模一样的例子来类比」
- **方法论的使用**: 指出这是思维障碍；应跳出原意，按行为找近似、可出图的类比。
- **结论**: 前提是有逻辑；追求近似和行为画面，不追求原领域复制。
- **结果**: 作为原则和避坑讲授。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一段材料本身有步骤、因果或行为逻辑，用纯谐音总觉得把意思拆没了。
2. 已经记住框架，细节记不住，需要补钉。
3. 卡在「我想不到本专业里现成的例子」。

### 语言信号

- 「类比记忆 / 万能类比 / 类比框架」
- 「不要只用谐音，把内在逻辑丢掉了」
- 「先框架再谐音修饰」

### 与相邻能力的区分

- 与 `universal-phonetic` 的区别: 有逻辑时本卡在前，谐音在后做修饰。
- 与 `intersection-loci` 的区别: 交集是用已有元素交汇出位置来「消掉」好记的部分；类比是借用行为逻辑整体。可以连用。
- 与 `three-dimension-conversion` 的区别: 转化是总出图框架；本卡是「利用信息自带逻辑」的专门路径。

## E — 可执行步骤 (Execution)

**必需输入**: 待记材料。先判断它有没有内在逻辑（步骤、行为、因果）。没有逻辑则停止本卡，转谐音或其他编码。
**交付物与完成标准**: 一个带行为的类比框架，加上对未被覆盖细节的谐音修饰。完成标准：框架可出图、导向指向原意的逻辑，细节有着落。

1. **判定能不能类比**  
   有逻辑性才继续。
2. **忽略逻辑主体，抓行为**  
   不要死盯原词所属领域；找出行为词，或把若干词合成一组。
3. **做近似的类比框架**  
   追求能出动作画面的近似，不追求一模一样的本领域案例。
4. **谐音修饰边角**  
   框架记不住的细节，交给 `universal-phonetic` 和 `recall-orientation-revise`。
5. **检查导向**  
   若类比只有抽象相似、没有图，或和别的逻辑太像，补画面或换框架。
6. **判停**  
   用户要的是并列要点如何在同一场景里不撞车，转到交集定位。

## B — 边界 (Boundary)

- 「开悟、识人」不作为本卡的交付物。
- 不要把 10/27 对「逻辑关联本质像太阳」（发散或再往前走一步）写成已交付的万能逻辑关联框架；完整框架仍在缺失的结尾课（nr01）。
- 没有逻辑的材料不要硬类比。
- 10/29 文稿与 10/27 后半高度重合，证据以 10/26–27 为主，不重复计数为另一套方法。
