## I — 方法论骨架 (Interpretation)

只画大而全的思维导图，并不会让人真正记住。工作记忆一次只能抓住大约 7±2 项，超大的彩色结构图不增加记忆效果；没有提取路径时，脑海中只剩模模糊糊的轮廓，细节一问就空——这就是「整体记忆骗局」。连「导图 + 细节提问」也仍然不够。

导图并非完全无用。它可以整理信息、化繁为简、梳理逻辑，但是马仔：真正承担记忆的是记忆宫殿（本课语境下尤其是 AI 记忆宫殿）。把导图当成王者，就会用画图替代做题和编码。

一份导图要有效，必须有「三配」：

1. 帮助理解的案例或理解图；
2. 助记联想（宫殿、残缺刺激等）；
3. 能实际解决问题的习题。

诊断时先抽查细节，再按三配找缺口；需要接近完整默写时，再把整理好的材料交给场景编码，而不是继续把导图画得更大。

## A1 — 应用示例 (Application Example)

### 示例 1: 学员狂画约 80 张导图后成绩下滑
- **类型与来源**: 讲者转述 / 00:55:45–00:58:32
- **问题/输入**: 学员听从「必须结构化、画导图、碎片化都是垃圾」的说法，停做题，画了大量导图
- **方法论的使用**: 用整体记忆骗局来解释——整理和换彩笔代替了提取与练习
- **结论**: 系统化的感觉不等于记住。
- **结果**: 讲者称其由一本水平降至约 480 分并复读。此为转述，本讲未见原始成绩单。对外说明建议匿名。

### 示例 2: 有效样例——医学讲义里的三配
- **类型与来源**: 讲者展示的学员教案 / 01:28:37–01:30:28
- **问题/输入**: 关于水溶性 / 脂溶性增大等内容的导图
- **方法论的使用**: 配上帮助理解的图画、助记用的残缺刺激，并布置课后习题
- **结论**: 这样的导图才算有效；只有大图没有三配的，讲者称为废品。
- **结果**: 作为合格对照展示，未给班级成绩对比。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 画了很多思维导图或知识结构图，一提问就答不上来，或成绩下降。
2. 想确认「我这份导图能不能承担记忆」，以及缺了哪一配。
3. 纠结要不要继续把导图画得更大、更系统，还是该改做编码和练习。

### 语言信号 (用户的话里出现这些就应激活)

- 「我画了很多思维导图为什么还是记不住」
- 「这是不是整体记忆骗局 / holistic memory illusion」
- 「导图要怎么三配才有效」
- 「结构化、系统化了，细节却问不出来」

### 与相邻能力的区分

- 与 `strong-association-scene-expansion` 的区别: 本卡先诊断整理物是否有效；确认需要近乎默写后再交给场景拓展。
- 与 `intersection-loci` 的区别: 交集定位是助记的一种实现，属于三配里的第二配，不是诊断框架本身。
- 不要把「问几个细节」当成已经完成记忆，本讲已用反例说明这还不够。

## E — 可执行步骤 (Execution)

**必需输入**: 一份导图或等价的结构笔记；学习目标（理解 / 做对题 / 接近默写）。最好有使用者的自测结果；没有则由本卡设计抽查问题。
**交付物与完成标准**: 诊断结论（是否整体记忆骗局风险）、三配缺口表、补救清单（理解案例、助记、习题；若需默写则转出场编码）。完成标准：每一配都有「已有 / 缺失 / 如何补」；不把「再把图画大一点」当作补救。

1. **写清学习目标**  
   理解、刷题、近乎默写，三者对补救的要求不同。
2. **做细节抽查**  
   按导图分支提出具体问题（原书例：「匀强电场有哪三个方面？」）。完成标准：记录能答、部分能答、不能答。若大部分不能答，标出整体记忆骗局风险。
3. **对照三配逐项检查**  
   有没有真正帮助理解的例子或图？有没有助记（宫殿、残缺刺激，而不只是彩色线条）？有没有实操作业？缺哪项补哪项。跨学科案例原书没有模板，须如实标明「需按学科自行补例子」，不能伪造权威案例。
4. **纠正主从关系**  
   保留导图的整理功能，明确记忆主体是宫殿/编码和练习，不是导图本身。
5. **按目标升级或停**  
   需要接近完整默写：把已整理材料交给 `intersection-loci` 或 `strong-association-scene-expansion`。目标只是理解或做题：补案例和习题即可，不必上大招。
6. **判停**  
   不要建议用户继续用换笔、加层级来「增强记忆效果」。不要仅凭本讲转述案例承诺分数回升。

## B — 边界 (Boundary)

- 不要把本卡理解成「禁止使用思维导图」。禁止的是把整理当成记住。
- 不要只加细节提问就宣布问题已解决。
- 工作记忆「7±2」是用来反对超大总图的经典表述，不要当成精确生理常数去计算分支数量。
- 曾宇航案例是转述，用来说明机制，不是可复用的统计证据。
- 对需要理解的科目，补助记之前必须先补理解，否则会变成盲目使用技术。
