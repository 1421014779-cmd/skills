## I — 方法论骨架 (Interpretation)

编码（转化出图）有六条原则。课堂用口诀「涂岛边煮熟，熟鱼整」帮助记忆，但讲者在口诀段没有逐字对应到原则名称，执行时以讲授顺序和明确编号为准，不臆造口诀映射。

可核实的条目如下：

1. **有图，以框定回忆导向**（在点名「第二个」之前讲授）：记东西必须有图才有明确导向。没有图，即便有逻辑关联，也容易前后混淆。反对把图像仅仅理解成「做加法」；也反对「逻辑做减法、图像做加法」这句流行口诀——图像的核心功能是框定回忆导向。
2. **辨识度**：内视觉本身很模糊。若图像是「一张写满字的保证书」，大脑辨不出它是保证书、计划书还是合同。要换成能一眼辨认的物象。
3. **突出记忆主体**：画面必须让人感觉到目标信息，而不是只造一个插入了该词的句子。例：要记「及时」，「一个人走到家门口」看不出及时；「到家门口时大雨砸在鞋跟上」才能感到及时。
4. **尽量用更少的图像回忆更多的信息**：高手一个图带出多个要点；图像串也受大约 7±2（课堂说控制在 5–9）限制，图多了同样会忘。紧挨着讲授的是 **不要有多余的陈述**：脑中过图和记录联想时，不要写心情、不要写小说，只表现要记的东西。二者都指向「少而准」，转写未再单独点名「第四 / 第五」，执行时作为相邻的两条检查，不强行拆口诀。
5. **用符合认知、见过、熟悉的事物和关系**：不要用没见过的角色和陌生关系硬编（如不熟悉的「李尔王」）。应用记忆是动态编码，应谐出熟悉关系。
6. **先整体后局部**（明确为最后一条，也是最重要的）：先抓住整体框架，再补局部；并否定固定编码。讲者用「借力」说明：调用大脑里已有的义群（含义群体、生活里见过的一整串行为），而不是用固定代码把每个词打成陌生故事。

## A1 — 应用示例 (Application Example)

### 示例 1: 「保证书」辨识度不够
- **类型与来源**: 原书反例 / 10/20 00:36:34
- **问题/输入**: 把「保证」编码成保证书
- **方法论的使用**: 内视觉看不清纸上的字，无法与合同、计划书区分，判为辨识度不合格，需换可辨认的物象。
- **结论**: 出得了「一张纸」不等于辨识度够。
- **结果**: 课堂反例。

### 示例 2: 「及时到家」要突出主体
- **类型与来源**: 原书例题 / 10/20 00:36 后
- **问题/输入**: 画面是一个人走到家门口，目标词是「及时」
- **方法论的使用**: 该画面看不出及时；改成到家时大雨砸在鞋跟上（或小孩将摔下时被脚勾住）等能感到「及时」的瞬间。
- **结论**: 造句里插入目标词无效，必须让画面表现该词。
- **结果**: 课堂示范。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 已经出了图，但提取时懵、混、或导向到别的近义词。
2. 听说「逻辑做减法、图像做加法」，不确定该不该按这句话做。
3. 一组编码图太多、联想写成小作文，或用了自己没见过的事物。

### 语言信号

- 「编码六原则 / 转化六原则 / 涂岛边煮熟」
- 「辨识度 / 突出记忆主体 / 先整体后局部」
- 「逻辑做减法，图像做加法」

### 与相邻能力的区分

- 与 `recall-orientation-revise` 的区别: 那张卡是发现导向偏移后换图或修饰；本卡是出图时就要对照的六条清单，第一条即框定导向。
- 与 `sequential-pegs` 的区别: 八原则管一组桩的关系；六原则管编码出图本身。「庄子八原则」是「桩子八原则」的口误。
- 与 `universal-phonetic` / `analogy-memory` 的区别: 那两张卡负责怎么出图或先立框架；本卡负责出完后按六条验收。

## E — 可执行步骤 (Execution)

**必需输入**: 目标信息与现有编码图像（或准备新编的草稿）。
**交付物与完成标准**: 按六条逐项通过（或标明哪一条未过、如何改）的图像方案。完成标准：有可辨认的图、导向指向目标、主体突出、图尽量少、陈述不啰嗦、关系熟悉，并且先有整体再补局部。

1. **先问有没有图、导向指向谁**  
   无图或只靠抽象逻辑，先补图。反对用「逻辑减法、图像加法」当指导思想。
2. **查辨识度**  
   闭上眼能否把这件东西与相近文件/物象区分开。
3. **查是否突出目标信息**  
   只插入了词、看不出该词，就改画面或修饰。
4. **查图是否过多、陈述是否多余**  
   能用一个熟悉画面带多个要点就合并；删掉与目标无关的情节。
5. **查是否熟悉**  
   没见过的事物和陌生关系打回重配。
6. **先整体后局部**  
   先立框架或借用已有义群，再补细节；不要一上来用固定代码逐字打成陌生故事。
7. **判停**  
   问题出在一组桩的跳跃/包含关系，转到 `sequential-pegs`。需要谐音发散，转到 `universal-phonetic`。

## B — 边界 (Boundary)

- 口诀「涂岛边煮熟，熟鱼整」只作为记忆辅助；因讲者未当堂逐字揭晓对应，本卡不发明对应表。
- 「第四 / 第五」在转写中没有被再次点名，本卡把「少图多信息」与「不要多余陈述」作为相邻检查，把「熟悉事物和关系」放在第 6 条之前、且计入前五条的讲授块中；若后讲或讲义给出官方命名，以讲义为准修订。
- 图像串「5–9 / 7±2」用来限制数量，不要拿去精确配额。
- 「先整体后局部」段夹有较长的借力/创业比喻，执行时只保留与编码相关的「借用已有义群、否定固定代码」；创业比喻进 reference。
- 「超遗忘规律 / 在线记忆」在本讲后半出现，用作「符合原则的编码可以不那么依赖时间表」的经验说法，不写成科学定律。
