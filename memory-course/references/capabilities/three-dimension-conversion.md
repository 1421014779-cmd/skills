## I — 方法论骨架 (Interpretation)

现代记忆宫殿的源头，不是先去背一座现成的楼，而是转化：把要记的信息变成可想象的具体事物。10/16 把转化说成两个方向、三个维度。

两个方向：
- 抽象转化为具体（抽转具），这是做桩和编码的前置；
- 把信息转化成「提问和答案」，服务输出与提取，而不是只把句子抄成图。

三个维度（讲者说「转化维度其实就这三个」）：
- **逻辑含义**：优先用字面/内在逻辑；外形逻辑也可以，但用得较少；
- **谐音**：10/16 已给出本质并因学员转化偏弱而提前开讲、让当堂开练：单音单字先出图，再动态发散，再组合成逻辑最好的画面；名、动、状等发散方向在同讲后半出现。完整主体、系统练习与避坑仍以 10/22 为准，本卡不写成已完成的「万能谐音」全流程；
- **动作**：包括谐音动作和逻辑含义动作，让画面能动起来，而不是静态贴标签。

产物是桩或编码。转化之后通常要进入序列桩、内定位或宫殿，而不是停在「我想到了一个东西」。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到抽象概念、术语、原则，还没有可想象的物象。
2. 已经在做宫殿或序列桩，但每一步都卡在「这个词怎么变成东西」。
3. 只听说谐音，想先用已讲清的三维框架起步，而不是空等 10/22。

### 语言信号

- 「抽象转具体 / 三维转化 / 抽转具」
- 「现代宫殿的源头是转化」
- 「谐音怎么出图（只问到 10/16 已讲的本质）」
- 「信息怎么变成提问和答案」

### 与相邻能力的区分

- 与 `sequential-pegs` 的区别: 本卡产出具体物象；序列桩卡把物象排成合格序列。
- 与 `recall-orientation-revise` 的区别: 转化是第一次出图；修饰卡处理「图会导向错误词汇」时的换图或二次加工。
- 与 `encoding-inventory-reuse` 的区别: 先查库存和熟句，再对剩余部分做转化。

## E — 可执行步骤 (Execution)

**必需输入**: 待转化的信息（词、句或一组概念）。
**交付物与完成标准**: 每条信息对应的具体物象或「问题–答案」对，并标明主要用了哪一维（逻辑/谐音/动作）。完成标准：输出必须是可想象的具体事物或可提取的问答，不能仍是抽象标签。

1. **先看库存**  
   若有现成熟句或联想库存，先走 `encoding-inventory-reuse`，只转化剩余部分。
2. **选方向**  
   要做桩/编码：抽转具。要服务于提取或理解：把信息改写成提问和答案。两条可以并存。
3. **在三维里选路，可组合**  
   优先逻辑含义（字面逻辑先于外形逻辑）；逻辑走不通再考虑谐音（按「单音单字出图 + 动态发散 + 组合出逻辑」的提纲，细节标注「完整教法见后讲」）；需要画面能跑起来时加动作（谐音动作或逻辑动作）。
4. **把产物交给下游**  
   做序列则到 `sequential-pegs`；做单条定位到 `internal-loci-encoding`；出图后提取不准到 `recall-orientation-revise`。
5. **判停**  
   用户要完整「万能谐音」逐步练习，转到 `universal-phonetic`。
