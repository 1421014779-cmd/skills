## I — 方法论骨架 (Interpretation)

普通人的机械记忆弱，还容易受到前摄、后摄抑制。把刚背完的材料全部蒙上，试图一次性白板默写，多数人会「十问九不知」。反复失败会变成创伤记忆，并强化「我脑子不行」的信念。少数机械记忆极强的人也许能扛住，但本方法针对的是普通人。

正确做法是及时、佛系、短促：每次只用一小块提示（讲者称为「视觉锤」或残缺刺激）带出一小块信息，把单次提取量控制在工作记忆大约 7±2 的范围，让复习以正反馈为主。复习的本质常是面对遗忘，但策略上要尽量把每一次提取做成「能想起来」。

艾宾浩斯式的固定时间节点（5 分钟、30 分钟、12 小时……）不是重点。讲者主张：若编码本身提供了可追踪的线索（如定位/宫殿），多年不按该时间表复习仍可能提取；把时间表当核心，会把努力用在低效路径上。这一判断主要来自课堂演示和个人体验，不是受控实验，执行时作为「不要把时间节点当成复习的主体」，而不是「永远不必再看」。

10/13 课初补充了强度判定（卡壳标「初记」，「全是卡的跟拖拉机似的」标「陌生」，非常流畅标「精通」；精通后可以不再复习。没有专用软件时，也可用文件夹或卡片实现「先给提示、再对答案」。

## A1 — 应用示例 (Application Example)

### 示例 1: 用视觉锤一段一段提取，而不是整页白板默写
- **类型与来源**: 原书课堂演示 / 10/12 00:23:56–00:26:07
- **问题/输入**: 一组已编码的法律要点（影响力贿赂、斡旋贿赂等）
- **方法论的使用**: 先看一个图像线索，只提取这一锤带出的几点；再看下一锤（牢房铁架、踢球的人等），而不是把整页盖住一次写完。
- **结论**: 「一丢丢视觉刺激带出一丢丢信息」，比一次回忆很多更不容易全军覆没。
- **结果**: 课堂当场提取顺利；无延迟对照实验。

### 示例 2: 反对「必须按时间表复习」的定位提取
- **类型与来源**: 讲者亲历演示 / 10/12 00:39:57–00:41:30（与 11/3 教师劳动特点例为同一条定位）
- **问题/输入**: 宣称数年未按艾宾浩斯节点复习
- **方法论的使用**: 仍沿小学课堂定位提取「长期性、示范性」等要点，用来说明「时间节点不是记忆的重点」。
- **结论**: 可提取路径比日历更关键。
- **结果**: 课堂演示成功；「4 年 / 5 年没复习」为讲者自述，未提供独立记录。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 背完就蒙上整页默写，经常什么都写不出，越复习越挫败。
2. 正在用艾宾浩斯、Anki 固定间隔当唯一复习策略，想改成「先给线索再提取」。
3. 已经做了定位或宫殿，但不知道日常怎么复习、复习到什么程度可以停。

### 语言信号

- 「白板复习总是全忘 / 蒙上就写不出来」
- 「还要不要按艾宾浩斯时间点复习？」
- 「残缺刺激复习 / cued recall review / 视觉锤」
- 「这组材料复习到什么程度可以先停下？」

### 与相邻能力的区分

- 与 `designed-output-learning` 的区别: 那张卡管「学习时如何设计输出」；本卡管「已经编码之后如何复习」。
- 与 `internal-loci-encoding` 的区别: 内定位是做提取路径；本卡是日后怎么用那条路径做短刺激复习。
- 与 `mindmap-sanpei-audit` 的区别: 导图诊断处理「只整理不提取」；本卡给出具体的复习动作。

## E — 可执行步骤 (Execution)

**必需输入**: 已编码或至少已学过的材料；现有复习方式（可选）；是否已有图像/定位线索。若材料从未编码且用户只想「安排时间表」，先说明本卡不靠时间节点，并询问能否先做编码或至少准备残缺提示。
**交付物与完成标准**: 一份复习方案：每次提示是什么、一次提取多大一块、强度如何标记、何时停。完成标准：不能出现「把整份材料盖住一次性默写」作为主策略。

1. **禁止主策略用白板整页默写**  
   说明它对多数人会产生大面积失败和创伤记忆。完成标准：方案里的单次任务是「一小块」。
2. **准备残缺刺激**  
   优先使用已有定位/宫殿/图像中的一小块可视线索；没有图像时，用关键词、问题或部分标题，但一次只给一个锤。不要一次甩出整章提示。
3. **短提取**  
   只要求回忆这一锤能带出的内容（大约控制在工作记忆可抓的一小撮）。成功后再进下一锤。失败则再给稍多一点线索，而不是立刻改回整页默写。
4. **标记强度**  
   卡壳→初记；很生→陌生；流畅→精通（可降低频率或暂停）。完成标准：每块都有标记规则。
5. **不要把日历当主体**  
   可以有一个大致回头看的习惯，但检查的是「线索在能不能提出来」，不是「有没有挨到第 7 天」。讲者用多年后仍能沿定位提取来反对时间表迷信；执行时不得承诺「一次编码、永远不必再看」。
6. **判停**  
   若用户其实还不会编码、提示本身质量很差，转到编码类能力（内定位、三维转化、序列桩等）。若问题是「学的时候只抄笔记」，转到 `designed-output-learning`。

## B — 边界 (Boundary)

- 不要把「反对艾宾浩斯时间表」写成「科学已经否定间隔重复」。本讲的要点是：有高质量提取线索时，不要把时间节点当成核心；间隔重复本身在其他传统里仍有大量证据。
- 「多年不复习仍能提取」是讲者体验和课堂演示，不能写成保修条款。
- 工作记忆 7±2 用来限制单次提取量，不要拿它去精确计算必须锤出几条。
- 本卡不教如何从零编码。
- 专用「读书会软件」只是实现形式；方法不绑定该产品。

10/20：细节提问回答「本质上也是一种残缺刺激」；不会记忆术时用细节提问，会了则残缺刺激加细节提问。存储强度的核心是联想时残缺刺激的质量。

10/30 给出三分：**傻子记忆**是花了时间却用不出去、模模糊糊待在脑子里的记忆；**整体记忆骗局**是只有朦胧的整体熟悉感；**永久记忆**则像可终身调用的记忆。复习最重要的是「高质量的」残缺刺激。四表复习（往精通表递进）与本卡初记/陌生（或 11/2 所称「熟悉表」）/精通是同一套强度管理，11/2 把中间档改口为「熟悉表：能过但不流畅」——执行时允许「陌生/熟悉」两种叫法，以「卡、能过但不流畅、可停」三档为准，不另造第四档。

11/2 对照 **动态复习** 与 **静态/二元判定**：记不住就增加残缺刺激的数量和质量（投喂资源），追求正反馈，不要像 Anki/墨墨那样只卡时间节点并判定成败。回忆失败，一般先查刺激质量是不是太差；纯提问作为残缺刺激档次较低，时灵时不灵。一次仍然不要复习太多。
