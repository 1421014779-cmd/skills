# 六组转化测试过程（仅案例）

> 这是 2026-11 用 fish 提供的材料做的六组转化测试记录。这里**只记录实际尝试与评价**，不构成通用规则，也不覆盖课程原文方法。
>
> 每组写：原文与关键词、尝试过程、fish 的纠正或评价、采纳/未确认状态。语音转写含糊处标「（不确定）」。
>
> **不要把「好，我们来测下一条」或未提出纠正，当成该方案已被验证有效。** 某次被采纳，也只说明这一组当时怎么收场，不把它升级成以后必须照做的步骤。

---

## 第 1 组：工作流

**原文与关键词**
- 原文：工作流（workflow）：LLM 与工具通过预定义代码路径编排，控制流确定性（每次执行路径完全可预测），LLM 只在路径节点内起作用。
- 关键词：**定轨**。

**尝试**：桌面轨道小火车，铁轨提前铺好，站里的机器人只用工具干活、不能改道。用类比，没硬加谐音。助手还校准了原文：预定义不一定每次路径完全相同，也可按预设条件分支。

**fish 的评价**：没有纠正，直接说「好，我们来测下一条」。

**状态**：未纠正，也**未验证有效**（「测下一条」只表示继续下一组）。

## 第 2 组：智能体

**原文与关键词**
- 原文：智能体（agent）：LLM 动态指挥自身流程与工具调用。内核是「环境反馈 → 规划 → 工具调用 → 检查」的循环，每步从环境获取 ground truth；必须配停止条件和人工检查点。两者统称 agentic system，是同一光谱的两端而非对立物。
- 总关键词 **掌舵**（fish 说「很形象」，是智能体的概括）。他想记住下面的组成，助手再拆出：**实况、规划、调用、检查、停止、人工、光谱**。

**尝试**
1. 七个词全用类比挂进驾驶舱：前窗、海图桌、船舵、仪表盘、油门杆、对讲机、控制模式面板。
2. 被指出后改成前三个类比；检查=仪表台茶杯里的小木签（「签茶」）；停止=舱门边有人疼了脚趾（「疼趾」）；人工保留原词。助手自己评价「疼趾」读音不贴、画面不自然。

**fish 的纠正（本组当时的意见）**
- 类比「很完美」，但六个词全靠类比不好，「类比可以用上三个或者两个，其他最好能用上谐音和交集」。
- 检查改为**捡茶杯**：转船舵时茶杯掉在地上，船长去捡。他说两个字谐音后「可以在中间加一个字」做修饰（加的「杯」是辅助字）。
- 停止改为**收油杆**：fish 提议「停止可以当成收油杆」，并问船上一般是刹车还是杆子（他没见过那种）。

**后来对照表里的写法**：掌舵（总）、实况=前窗、规划=海图桌、调用=船舵、检查=捡茶杯、停止=收油杆、人工=对讲机请领航员确认、光谱=控制模式滑杆。

**状态**：捡茶杯、收油杆为 fish 当组明确提出或认可；「类比用两三个、其余用谐音和交集」是他当组的意见，**不是已写入课程的通用规则**。光谱等条目出现在后来整理的对照表里，当组对话未逐项确认。

## 第 3 组：五种工作流模式

**原文与关键词**
- 原文：五种工作流模式（构建在 augmented LLM，即挂了检索、工具、记忆的模型调用之上）：提示链；路由；并行化（切块 / 投票）；编排者-执行者；评估者-优化者。
- 关键词：总 **五式**；底座 **装备**；**链条、分流、并行、派工、改稿**。fish 同意往下做场景。

**尝试**：街边图文打印店。门口自行车=链条，接待台=分流，并排工作桌=并行，店长桌=派工，校样台=改稿；门边装备柜=装备。只用类比。

**fish 的纠正与后来的改法**
- 指出「并排工作桌」和「店长的桌子」重复了。助手建议把派工聚焦为裁纸机旁分派订单的店长；最终对照表写的是「店长接临时订单，现场拆活派人」，**是否改成裁纸机旁，记录里未明确**。
- fish 提出：限定场景应和材料有关，把材料特点形象化放进场景。助手先给了「同一份原稿、五种处理方式」，fish 说有点怪，要求用第一性原理审视。
- 后来改成：**给装备齐全的机器人印手册的打印店**（放大镜=检索，工具箱=工具，记事本=记忆）。五个内部点位保留。fish：「我觉得这个就可以了，已经很贴近了」。
- 另有一句转写不清，大意像是「组内（点位）重复的话，换一个就行；谐音其实简单，整组外面的场景限定才比较难」（不确定）。

**状态**：机器人印手册这一版，fish 表示「已经很贴近了」。派工点位的最终形态未完全确认。当组意见不升级为通用规则。

## 第 4 组：简单优先（温泉屋）

**原文与关键词**
- 原文：简单优先的机制：复杂度以 latency（延迟）与成本为代价换表现；错误在多步链中复利累积。多数应用优化单次 LLM 调用已足够；升级复杂度的唯一正当理由是评估数据（evals）证明简单方案不够。
- 关键词经过纠正后为：**从简**（总）、**权衡**（用延迟成本换表现）、**误差**（多步累积）、**单次**、**实测**（评估数据证明才升级）。fish 确认这五个词没问题。此前助手先提「简用」后改「从简」，并用「单次」去提示「复杂度换表现」；fish 指出这样对应有误，「单次」应放回「优化单次调用已足够」那一句。

**尝试（多次被否）**
1. **果汁店**（单台榨汁机、凭检测决定是否加设备）：fish 说「这组不太对」，问题先出在关键词与原文句子的对应。
2. 五个词各转成独立物象（剪葱、天平、刻度印错的尺子、鱼刺、实际测量）：fish 要求放回同一个交集场景，「只是单词，衔接不到一个场景里面去」。
3. 再挂回果汁店（备料台剪葱、收银台天平、连续加工台、主榨汁机、店后检测台）：fish 说「很一般」，并逐点反问（果汁店哪来的葱、门口是否放秤、单次与主榨汁机的关系、哪家店做完先检测再给人喝等）；同时对比第 3 组打印店的落点「都是有可能的」。
4. **裁缝店**（只挂权衡/误差/实测：布料架、裁剪台、试衣镜）：fish 未评价这家店，而是提醒限定场景最好从关键词里提取；提取不了也不一定非要提取。

**后来收到的改法与当组确认**
- fish 提出用谐音把字含进场景名：「泉，温泉，误差乌，温泉屋」；屋里本来有石头，用「石」提示「实」。
- 助手曾把泉/权等说成「近似」；fish 指出它们是同一拼音，只是声调不同。
- 助手曾把「从简」「单次」两个字都编进去（碱盐盆、担瓷壶伙计）；fish 说两个字没法一起谐音时，提取第一个字就可以，不要增加负担。
- 助手还留着走廊里挑扁担的伙计；fish：「泡温泉手担在石头上，这就完了呀，你还要再增加画面吗？」
- 当组画面：门口竹丛=从简；泉水池=权衡；木屋=误差；手担在池边石头上=单次+实测。fish：「好，这组就这样」。

**状态**：温泉屋这一版，fish 当组确认「好，这组就这样」。其中关于谐音、取字、合并动作的意见，都是这一组里的纠正，**不写成以后必须遵守的通用规则**。

## 第 5 组：工具定义（schema）三件套

**原文与关键词**
- 原文：工具定义（schema）三件套：name（按它精确分发）、description（模型选择的唯一依据）、input_schema（JSON Schema：类型+白话描述+required）。可加 strict:true 强制输出贴合 schema。
- 助手关键词：**分发 / 说明 / 填表 / 严格**。

**尝试**：药房场景。按名拉开药柜抽屉（分发）；顾客只看药盒说明书挑药（说明）；处方单上写类型、白话说明，星号为必填（填表）；药师推眼镜对照处方（严格：严→眼）。谐音查过练习用音表的 tian、yan 等行。

**fish 的评价与后续**
- 用户没有认可这一方案。
- 随后追问有没有用「提词六原则」。助手承认当时没有逐条检查；后来在课程已交付材料里核查，**没有找到名为「提词六原则」的条目**。
- 用户指向「提字口诀.jpg」。图上可见的内容包括：技巧一侧写中心思想、容易回忆、修饰、不提同音同形字；经验一侧写记忆惯性、记忆库存、逻辑盲猜推理、机械记忆能带一部分（用户口头澄清为「能代步」）；并写故事法一句话突出一个回忆信息点，口诀法每个字一个回忆点。
- **关于这张图的说明**：它是用户提供的补充资料，推测可能来自缺课或未随包交付的材料，**不能冒充已在本技能中证实的课程定论**，也不在这里把它定义成新的官方规则。仅作为本组测试的背景记下。

**状态**：关键词已提出；**转化方案未被认可**。不是成功案例。

## 第 6 组：「空」与两边见

**原文与关键词**
- 原文：「空」指无自性，不是物理上的空无，也不是未来一切归零。「凡所有相，皆是虚妄」破除的是把现象、标签和外在形象当成固定本质；它并不否定现象的因果作用。因此需要同时避免两边：实有见认为事物具有独立不变的实体；断灭见认为既然无自性，就不存在、无因果、无责任。杯子和碎片都没有固定自性，但二者作用、形成条件及结果不相同。
- 助手关键词：**无自性 / 破执 / 实有 / 断灭 / 有别**。

**尝试**：杯子贴着标签盛水；旁边是碎片。用手指着杯子，说把杯子当成独立不变的实体是错误的一边；碎片还需要扫帚清理，用来表达不能没有责任。定义本身打算直接记。

**fish 的评价（原话）**：「转化完全不对，然后提的字儿吧，嗯，还可以。」

**状态**：**关键词尚可，转化失败。** 不可当作成功案例，也不得从这一组倒推新的转化规则。

## 追加测试案例：八项材料选五个原信息桩子（2026-11-22）

> 本节是原六组记录之后新增的普通测试案例；保留测试过程、实际评价与未确认状态，不将本次结果升级成方法规则。

**原材料（八项，保留原字与关系）**

否认记忆；流动心识；人停止逐念；永恒本体；保持某种状态；念起；规划；行动。

这些是用户补充字后的待记材料，不是完整哲学原文；本案例不推断其义理。

**本次尝试条件**

用户要求先从原信息中选五个能共同构成场景的定位元素，让它们先承接五部分信息，再把其余三项挂上；先试五个能否记完，确实不够才增加。本版尝试不拓展位置。用户在 t109 要求收录这次测试；本节按 t113 的最新要求作为普通测试案例保留。

**助手实际给出的测试方案**

助手设定“带泳池、露天厨房的庭院民宿”，选五个原生定位元素：鸡翼、流水心石、煮鲶鱼锅、桂花树、端菜人。

| 定位元素 | 实际画面 | 对应原项与线索缺口 |
|---|---|---|
| 鸡翼餐桌 | 有人指着鸡翼，面前的人摇头、双手打叉 | 鸡翼→记忆；否定动作→否认。合起来提示“否认记忆”，但动作也可能被提取为拒绝，而非否认。 |
| 流水心石 | 水流绕过心形石头 | 流动＋心石→流动心识。 |
| 同一水区（挂入） | 心形石旁有人横着游泳 | “泳横”倒序提示“永恒”；“本体”没有独立线索，仅依赖整项补回，不算完整稳固编码。 |
| 煮鲶鱼锅 | 厨师关火、将锅端离炉头，停止煮鲶 | 人＋停止＋煮鲶→人停止逐念，保留“停止”关系。 |
| 桂花树 | 树本身 | 桂花→规划。 |
| 同一桂花树（挂入） | 树下的人捻起一簇桂花 | 捻起→念起。 |
| 端菜人 | 服务员迈步端菜 | 行走动作→行动。 |
| 同一端菜人（挂入） | 一边走一边调整双手，保持托盘水平、汤不洒出 | 提示“保持某种状态”；水平仅为编码所选状态，不替原材料指定状态。 |

**用户的评价与选择（与助手复盘分开记录）**

- t108 用户原话：“这一版太糙了”“我觉得第一版好”。
- 用户选择回到此前河边版：三个原生定位元素（流水心石、桂花树、游泳者）加两个拓展位置（长椅、下水台阶）。这表示相对偏好与后续方向，不表示第一版的所有细节已获认可；第一版仍有薄弱线索，未被逐项确认完成，也未验证记牢。
- 收录要求的后续更新：t113 用户要求“不要再把它写成反面案例了，就正常的一个案例”（授权消息 pt113u）。按最新要求撤去反面定性，保留方案、用户否定评价及回到第一版的事实。

**助手复盘（不是用户逐项诊断）**

- 为满足本轮“五个原信息元素”的数量条件，助手把泳池、厨房、庭院拼成一个宽泛场景；元素虽然能够共存，但共同场景的自然凝聚力不足。
- 部分线索的回忆导向薄弱，尤其“泳横”只提示到“永恒”，“本体”缺线索；鸡翼配否定手势也不能稳妥区分“否认”和“拒绝”。
- 为覆盖条目又附加摇头打叉、横泳、关火端锅、捻花、行走稳盘等动作，没有因使用五个原生元素而明显减轻编码负担。

**状态与边界**

本版按用户 t113 的最新要求作为普通测试案例留存，不再标为反面案例。用户对本版的否定评价与回到第一版的选择保持原样；本版没有被验证有效，改名不等于改写测试结果。不据此推出“五个定位元素必错”“必须采用三原生加二拓展”或“交集定位无效”等规则；不修改课程方法、能力卡或 SKILL.md。
