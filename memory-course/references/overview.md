# 书级理解 — 宁老师记忆术课程（memory-course）

> 作者：宁老师。输出语言：中文。本文件是整门课的阶段 0 骨架，并记录已核实结论。现有 16 份转写均已增量合并（含后到的 10/8 第三课）。开头、中间、结尾三处缺讲仍不编造。

## 一句话

这门课要训练的是一套可执行的记忆与学习技术：先转化、再做合格的桩与定位，用现代/AI 宫殿临场生成场景；学习靠设计输出，复习靠残缺刺激，而不是白板默写或艾宾浩斯时间表。

## 全书骨架（3–7 条）

1. 只把能指导后续思考和行动的高效规则练到接近「九九乘法表」那样可提取；学习最重要的动作是设计输出，复习最重要的动作是残缺刺激。
2. 任何信息先转化（抽转具，或改写成提问和答案），三维是逻辑含义、谐音、动作；产物是桩或编码。
3. 序列桩须满足八维度（口诀「宽丑挑包，强行熟悉」+ 明）：聚焦并与限定场景结合才叫桩，否则只是编码。图像提取若滑向别的词，换图或修饰以校准回忆导向。编码前先复用熟句与联想库存。
4. 现代/AI 记忆宫殿是围绕古典宫殿缺陷重设计的**能力**（临场生成无穷场景），不是提前背死固定地点。两者都用图像分割记忆负重。
5. 单条信息用内定位；并列或同义项用交集定位（2–5 元素，单空间尽量不超过 6）；多层材料用记忆块 + 强联系场景拓展（只用于需要接近完整默写的材料）。
6. 思维导图只整理，必须三配（理解案例、助记、习题）；把导图当成已经记住，是整体记忆骗局。
7. 有内在逻辑则先类比框架再用谐音修饰；无逻辑则走万能谐音。出图用编码六原则验收。结尾课预告的高效记忆原则与万能逻辑关联仍缺，不得预写。

## 方法 vs 非方法

进入能力池的，必须是学习/记忆上可执行的方法。自我成长、路程思维、自我效能、财富刀箱、创业故事、课堂调度和学员段子，只进 `references.md`。自律三原则（动态分组休息、降低难度、一定完成）与复习节奏有关的部分，吸收进残缺刺激复习的执行说明；完整「人生自律」体系不单列能力。
