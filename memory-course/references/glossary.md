# 术语词典 — 宁老师记忆术课程

> 定义按讲者在已蒸馏讲次中的用法，不是普通字典义。转写口误在括号中注明。11/3 试点词条已并入；批次 1 新增词条按 10/9–10/16 用法书写。后半讲次的定义已并入本表；缺讲若送来，只更新本表，不另起一套词典。

| 术语 | 讲者的用法 | 和常识的差异 |
|---|---|---|
| 自由回忆 | 没有抓手、靠机械记忆在脑海中直接找信息；对多数人很困难 | 强调「缺少发力点」的痛苦，不是中性的实验任务分类 |
| 线索回忆 | 用图像等作发力点来提取；最好同时场景化、具象化、关联化，并与场景结合以唯一 | 不是任意提示都合格 |
| 内定位 | 从信息 A 内部抓取一部分做成位置索引，再在该位置上联想 | 不是把信息丢到预先准备的无关宫殿房间 |
| 残缺刺激 | 日后只出现信息的一部分，就能触发已做好的位置索引；复习时则是「用一点一点的提示去刺激自己回忆」 | 既是编码后的提取开关，也是复习的主动作，不是把原题再做一遍 |
| 残缺刺激复习 / 及时佛系复习 | 及时、短刺激、短回忆；一次一个视觉锤，提取量大约控制在工作记忆 7±2；以正反馈为主 | 不是按艾宾浩斯时间节点排的复习表，也不是整页白板默写 |
| 视觉锤 | 一小块可视线索，用来带出一小块信息 | 不是一次把整章提示甩出去 |
| 白板复习 | 背完后把材料蒙上，试图一次性默写；讲者认为普通人常会「十问九不知」，易成创伤记忆 | 不是所有「闭卷回忆」都被否定，否定的是把它当主策略、一次回想过多 |
| 初记 / 陌生 / 精通 | 复习强度标签：卡壳为初记；「全是卡的跟拖拉机似的」为陌生；非常流畅为精通，精通后可以不再复习 | 是课堂操作标签，不是心理测量量表 |
| 设计输出 | 学习最重要的动作；按所学材料设计能驱动创造、回忆、应用的输出。没有设计输出的动作基本是废品或准备动作 | 并不禁止笔记和导图，只是说它们不能代替输出 |
| 当间谍 / 短输入 | 万能学习模型的前两步：先摸清要考或要交的「匪首」，再短输入，停下后马上做三种输出 | 不是让人少学，而是禁止「先灌完整章再幻想以后会记住」 |
| 三维转化 | 两个方向（抽转具；信息转成提问和答案）和三个维度（逻辑含义、谐音、动作）；产物是桩或编码。现代宫殿的源头是转化 | 不是先去背一座现成的楼 |
| 抽转具 | 把抽象转成具象，做桩和编码的前置 | 不是用抽象词直接当桩 |
| 万能谐音 | 单音单字出图，沿名、动、状发散，组合成熟悉关系；练习时优先状态和动作。10/22 已交付主体 | 不是整词谐英语多音节的公式；有内在逻辑时应先类比再修饰 |
| 序列桩 | 一组有顺序、能挂钩后续信息的具体事物；须先把信息变成母桩再做序列（转写作「序列装」） | 不是任意一串联想都叫桩 |
| 宽丑挑包，强行熟悉 | 序列桩八维度口诀：宽、抽、跳、包、强、形、熟，再加「明」（事物明确、顺序明确） | 课堂要求背到接近九九乘法表；「个性化 vs 共性化」是最难点，未单列为第 9 条官方原则 |
| 母桩 | 转化后得到的、可再编进序列的具体事物；也用于「文具盒」这类会包含后续项的反例 | 母桩若外延吃掉后面的项，就不能这样排序列 |
| 回忆导向 | 看到已编的图时，实际浮出的词是否就是目标词；不准就要调 | 图「好看」不等于导向正确 |
| 修饰 | 不换底图，做二次加工，把导向拉回目标词；应用记忆里的影像是流动的 | 不是第一稿就必须完美，也不是可以改到失去与原文的对应 |
| 传送门 / 编码库存 | 背所谓新句子前，先看有没有已熟的表达、已有的联想编码库存、以及前置知识库存，只编码真正的新块 | 不是从头把整段当成全新 |
| 古典记忆宫殿 | 预先背好的固定地点顺序（如罗马房间法）；讲者认为信息量大时地点难背、抽取困难、灵活性差（转写或作「点记忆供电」） | 不是「凡用位置就是古典」；有表演价值，但不是本课推荐的学习主力 |
| AI / 现代记忆宫殿 | 围绕古典缺陷重设计的能力：经训练能随心所欲制作无穷场景；不是一种固定形式（转写亦作 AIG 供电 / AIGC 宫殿） | 不是用 AI 搜答案，也不是把关键词无逻辑地拼进一张图 |
| 交集定位 | 用 2–5 个元素交汇出唯一场景，再把要点放到位置上，避免同义项撞车；单空间尽量不超过 6 个 | 不是把多个词画进一张没有位置分工的图 |
| 拓展位置 | 已有定位词不够时，在同一空间再找逻辑上稳定存在的位置，按空间顺序使用 | 不是另起一套与原场景无关的新宫殿 |
| 整体记忆骗局 | 只靠庞大思维导图（或再加一点细节提问）得到模糊轮廓，细节其实忘光，却以为已经系统化 | 并不否定导图的整理功能 |
| 思维导图三配 | 有效导图须同时配：理解用的案例或图、助记联想、实操作业 | 有很多分支不等于完成三配 |
| 记忆块 | 把要一起提取的一组要点打包，先记块，再记块与块的顺序（转写或作「记忆快」） | 不是一张包打全部层级的总图 |
| 强联系场景拓展 | 先把一层写入场景并记住，再以已记节点为逻辑起点拓展新场景承接下一层；用于大型多层、需接近完整默写的材料 | 不是一上来做多层总宫殿，也不是用一条长序列硬排整棵树 |
| 傻子记忆 | 花了时间却用不出去、模模糊糊待在脑子里的记忆（10/30） | 不是对学习者的贬称；与「已能调用的记忆」相对 |
| 生活记复习 | 把条目放到常路过的位置上，走过去就能复习 | 11/3 只有好处描述，没有完整选点方法 |
| 万能逻辑关联 | 在两个不相干场景之间建立足够强、足够独特的逻辑链。11/3 明确留到「明天」；该讲目前缺失 | 只有质量门槛和演示，不是已交付的框架 |
| 限定场景 | 桩必须是「A 事物 + 环境」结合产生的差异性；否则只是编码/废品。也用于防止不同来源的衍生序列撞车 | 不是可有可无的背景装饰 |
| 无限减法 | 所谓新材料里，熟的部分剪掉，只记不熟的部分（10/8） | 与传送门/库存复用是同一检查单 |
| 编码六原则 | 出图验收：有图框定导向、辨识度、突出主体、少图且不赘述、熟悉关系、先整体后局部。口诀「涂岛边煮熟，熟鱼整」未当堂逐字揭晓 | 反对「逻辑做减法、图像做加法」 |
| 类比记忆 | 有内在逻辑时，忽略原主体、抓住行为做成近似可出图的框架，再用谐音修饰细节 | 不是在本领域找一模一样的案例；没有逻辑不要硬类比 |
| 细节提问 | 问细节并回答；本质上也是一种残缺刺激，档次通常低于图像残缺刺激 | 不是与残缺刺激对立的另一种复习哲学 |
| 动态复习 | 记不住就增加残缺刺激的数量和质量，拿正反馈；不要二元判定成败（11/2） | 不是再发明一套与残缺刺激并列的时间表 |
| 永久记忆 | 可像九九乘法表那样调用的记忆；讲者认为图像更容易进入，且高质量残缺刺激有助于日后捡回 | 不是「背一次就终身不必再看」的保修条款 |
| 义群 | 一组已有含义的字/行为整体，编码时应借力调用，而不是用固定代码打成陌生故事 | 不是事先背死的数字桩 |
| 心理印象 | 定位存在于大脑对位置的印象里 | 实地改建只要印象还在仍可用 |
