# 决策规则速查 — 宁老师记忆术课程

| 能力 | 一句话规则 |
|---|---|
| 内定位编码 | 从信息内部取出一部分做成位置索引，在位置上联想，靠残缺刺激追踪提取。 |
| 稳定定位四原则检验 | 用「小而准且强相关、印象固定、情感加持、位置即转化主体」检验并改写不稳的定位。 |
| AI 记忆宫殿场景构造 | 为记忆术写逻辑自洽、元素丰富、彼此差异大的场景和文生图提示词。 |
| 交集定位（含拓展位置） | 用 2–5 个元素交汇出唯一场景，按空间位置记一组要点；不够就在同一空间拓展，尽量不超过 6 个位置。 |
| 强联系场景拓展 | 把一层打成记忆块写入场景，再从已记住的节点逻辑拓展新场景承接下一层。 |
| 思维导图三配诊断 | 用细节抽查和「理解案例、助记、习题」三配，判断导图是否陷入整体记忆骗局并给出补救。 |
| 残缺刺激复习 | 用一小块提示带出一小块信息来复习，不把整页默写或艾宾浩斯时间节点当主策略。 |
| 设计输出学习 | 先当间谍摸清要交什么，短输入后立即按目标设计输出；只把能指导行动的规则练到可提取。 |
| 序列桩构造与八原则 | 把信息变成母桩再排成序列，用「宽丑挑包，强行熟悉」加「明」检验，没有限定场景的只是编码。 |
| 三维转化 | 沿抽转具或提问—答案两个方向，用逻辑含义、谐音、动作把信息变成具体物象或可提取问答。 |
| 修饰与回忆导向 | 提取时若图像滑向别的词，就换图或在底图上做修饰，把回忆导向拉回目标词。 |
| 编码库存复用 | 面对所谓新句子，先复用已熟表达、联想编码库存和前置知识，只对剩余块做新转化。 |
| 万能谐音 | 把目标拆成单音，沿名、动、状发散并组合成熟悉关系；练习时先状态和动作，再配名词。 |
| 类比记忆 | 有逻辑的材料先忽略原主体、抓住行为做成近似类比框架，再用谐音修饰细节。 |
| 编码六原则验收 | 用有图框定导向、辨识度、突出主体、少图不赘述、熟悉关系、先整体后局部，验收并改写编码图像。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
