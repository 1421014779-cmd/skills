# 宁梓亦（宁老师）记忆术课程 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 缺失的开头讲次（10/8 为第三课，课 1、课 2 仍缺）、中间缺讲、结尾缺讲：不得编造其内容。
- 11/3 预告、10/27 亦提及将在「19 天最后一天」交付的万能逻辑关联完整框架。
- 自我成长、反人性口号、路程思维、自我效能完整体系、财富底层逻辑、创业与人生五关。
- 用记忆术替代理解、推导或解题策略。
- 把「多年不复习仍能提取」写成保修条款，或把艾宾浩斯批判写成已核实的科学史。

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 只把能指导行动的规则练到可提取；学习靠设计输出，复习靠高质量的残缺刺激，不把白板默写、艾宾浩斯时间表或 Anki 式二元判定当主策略。
2. 先转化再做桩或编码；序列桩须与限定场景结合；有内在逻辑则先类比框架再用谐音修饰，无逻辑再用万能谐音出图；导向不准就换图或修饰。
3. 编码出图按六原则验收：有图框定导向、辨识度、突出主体、少图且陈述不赘、熟悉关系、先整体后局部。
4. 现代/AI 宫殿是临场生成无穷场景的能力，本质是强烈的复习刺激，不是提前背死固定地点。
5. 单条用内定位，并列用交集定位，多层用记忆块加按层拓展；线索须场景化、具象、关联。
6. 思维导图只整理，必须三配；整体朦胧熟悉是整体记忆骗局或傻子记忆，不是可用记忆。
7. 需要理解的科目不能纯靠死记；缺失讲次与未交付的万能逻辑关联框架不得临场编造。
8. 转化技巧只在符合常理、说得通的前提下使用，不为转化而转化：能借交集或类比自带的逻辑就不硬搞，交集覆盖不到的才用万能谐音修饰（10/19 造句合理性、10/26–27「能不硬搞就不硬搞」、11/3 宫殿须合逻辑）。

## 交付格式

能力任务按下列四块输出，缺块补上，不要写成无结构随笔：

1. **路由**：能力名与路径；若加载了第 2 张卡，写明原因。若拒做或改走 glossary/overview，写判定依据（不适用哪一条）。
2. **方案**：按所加载能力卡的执行步骤分条给出，包含具体物象、提示、位置或改法，不要只复述原则。
3. **验收或下一步**：对照该卡完成标准，标明已过/未过项，或下一步该转到哪张卡。
4. **边界**：涉及讲者体验、缺讲、口诀未揭晓处，必须显式声明「不是保证/不得编造」。作者名用宁梓亦，不要写「未知讲者」。

查阅类问题（定义、书名、概览）不套本模板，直接简答。

## 边界与判停

- 用户只要查阅定义、不需要方案时，改用 glossary/overview，不编造宫殿或桩。
- 用户问的是缺失讲次的具体教法时，说明缺口并停止编造。
- 目标不是接近完整提取且材料很短时，停止上强联系场景拓展。
- 缺少待记或待学材料时先询问，不擅自替用户编造要背的内容。
- 涉及创伤性私人记忆时，未经同意不得要求使用。
