# 1. 目标、输入与交付

本 Skill 提供「国风 + 巨物美学」的提示词专业知识与判断方法，用于为该类题材编写可直接提交的图像或视频生成提示词。它不独立推进完整影片制作流程，可与拉片复刻、剧本生视频等完整流程 Skill 配合使用：那些 Skill 决定拍什么，本 Skill 决定这一镜的提示词怎么写。

用户可能提供的输入包括：参考影片或截图、想复刻的具体镜头、题材与叙事意图、已确定的角色与场景设定、交付规格（画幅、时长、分辨率）。其中用户明确指定的造型、配色、台词、场景与已选定结果具有最高权威，本 Skill 的默认值不得覆盖它们；用户未指定的视觉参数，按本 Skill 的默认区间补齐。

交付物是**提示词文本**：每条对应一个镜头、一种运动，包含尺度关系、构图机位、服化道材质、光与介质、影调与运动五个部分，并配套负向提示词。本 Skill 的责任止于提示词与参数说明，不承担生成提交、候选筛选与成片剪辑。

# 2. AGENTS.md 策略

当本项目将连续生成多个同风格镜头时，把已确认且低变化的参数写入 `AGENTS.md`：画幅与分辨率、三级色阶的具体色值、机位纪律（不用正俯、不用手持）、人物与巨物比例区间、肤色隔离要求、结尾处理方式。后续镜头沿用这些值，不再逐镜重新商量。

单个镜头的构图与内容、生成候选、进度与确认状态不写入 `AGENTS.md`，属于对应镜头或工作流。

# 3. 专业创作方法

## 3.1 先做四个判断，再落笔

写任何一条提示词前，先确定：**谁在什么巨物的哪个部位**、**要不要压人**（决定机位）、**这一镜的功能**（揭示/相处/转折/收尾）、**画面里最可靠的可数参照物是什么**。四个答案确定后，措辞基本就被决定了。

无法确定功能时先问用户，不要靠堆形容词补位。「唯美」「仙气」「宏大」是结果，不是指令，必须翻译成色相、明度、光向、介质浓度、运镜速度与材质。

## 3.2 巨物感的四个必要条件

**缺少任一条，画面就会退化成风景照。** 逐条核对：

1. **可数参照物**：至少一个物理量清晰的小物件——软梯的每一级木棍、青竹钓竿、团扇直径、茶盏、花瓣舟。汉服会模糊人体体块，人物本身不是好尺子；让人物做"物理量不清"的事，让道具做"物理量清晰"的事。
2. **倍数关系**：必须写出人物与巨物的比例，而非"巨大"。推荐人物高度占画面高度 1/8–1/12，人巨高度比 1:10–1:50，巨物占画幅 50%–70%。
3. **画框截断**：巨物至少一个方向延伸出画框（叶缘、茎、花瓣）。"看不全"比"看得大"更强。
4. **介质纵深**：雾、水汽或雨至少一种，且写明浓度与位置，让远景对比度衰减。

## 3.3 构图六参数

该风格"看起来统一"来自同一套数字，逐镜沿用即可：

| 参数 | 取值 |
|---|---|
| 水线/地平线 | 画面高度 1/3 或更低 |
| 人物位置 | 下三分之一，中下部中心偏侧 |
| 巨物占比 | 画幅 1/2–2/3，多占上方两象限 |
| 留白（天空/雾） | 约 1/3，置于上方或侧上方 |
| 画框截断 | 至少一侧 |
| 前景遮挡 | 占画幅边缘 10%–15%，虚化 |

**机位四选一，按情绪定**：贴水面低机位微仰（被压）、腰高平视（相处）、高机位俯拍（被吞没）、略低于视线微仰（敬畏）。全片禁止正俯与无人机视角——视角一高，巨物变模型，仙气消失。禁止手持与变焦：轨道感等于仙气，手持等于人间烟火。

## 3.4 三级设色

按**面积配比**写，不能只写颜色名：底色青绿/黛青/天青占 80%，中调藕荷粉/月白/象牙白占 18%，朱砂红或绯红锚点占 2%，且**全片锚点不超过两处**。锚点一多就变成彩色片。

影调固定五个词：中等偏低饱和度、暗部适度提亮带灰雾不压死、高光柔和滚降无死白、轻度高光弥散、整体柔焦降锐。走现代 CG 质感时**不加胶片颗粒**；要颗粒就不要同时要求"通透纯净"。

青绿环境最容易把脸拍成菜色，每条带人物的提示词都必须显式写"肤色白皙透粉，与环境青绿保持色相分离"。

## 3.5 光与介质必须配对

光向决定任务，介质决定层次，两者要一起写，分开写则都不成立：

- 顺侧光→给材质（衣料透光、叶面纹理）
- 正逆光/顶逆光→给轮廓（剪影、叶脉次表面散射）
- 全向漫射→给氛围（雨天、晨雾，无硬影）

体积光必须带介质才出得来，写法是"光束穿透潮湿薄雾"而非只写"有光束"。介质按用途选三档：贴地云雾（巨物揭示，切三层）、水面平流雾（舟行横移，国画留白）、雨丝与水帘（情绪转折）。

水面有个高级选择：放弃镜像翻倍，改用透射——"水面清澈透光，可见水下长茎，涟漪打散倒影，呈现悬浮失重感"。镜像让巨物变高，透射让世界失重，后者更耐看。

## 3.6 运动纪律

一条提示词只写一种运镜，全片只用一种速度。极慢推为主力（占一半以上），缓慢横移用于换场景，缓升用于揭示多层空间，固定用于人像与呼吸点。

升格要分级而非全片慢动作：水花、裙摆、飘落、倾倒、雨丝用慢，人物行走攀爬对视用正常速度。

## 3.7 瑕疵规避要用"改内容"解决，不能只加负向词

该题材的已知高频瑕疵与对应规避，优先改画面内容，负向词只作兜底：

| 瑕疵 | 规避方式 |
|---|---|
| 人物在叶面滑步、脚部悬空 | 不让人脚明确踩在荷叶上，改为站在浮台或走在雾中 |
| 流体呈胶状（倒茶、水流） | 避免手部操作特写与液体倾倒动作 |
| 复杂结构边缘熔合（梯与叶交界） | 减少人物与复杂结构的接触面 |
| 手指变形、手脸粘连 | 手不遮脸，手不出现在脸侧 |
| 水面无波纹、行船无阻力 | 用雾遮住水面细节，不拍清晰的划水 |
| 皮肤蜡质、磨皮过度 | 显式写"肤质细腻真实，无蜡质感" |

同时限制人物不做大幅奔跑攀爬——这类片最稳的镜头都是人物近乎静止的。

## 3.8 节奏配方

一条提示词等于一个镜头。所选模型明确支持多镜头单次生成时，才在提示词内用"镜头1：……（3秒）"编号，且只在同一场景内合并，换场景必须拆分。

全片节奏顺序不可颠倒：前 30% 用 2–2.5 秒密集切换建立世界规则，中间 50% 拉到 3.5–5 秒长镜写意，最后 20% 留下最长镜。先密集抢注意力，再放缓换审美评价；反过来片子会散。收尾停在人物回眸或静立，不交代后续，强拍后干净收束。

## 3.9 交付前验收

每条提示词提交前核对：可数参照物、倍数关系、水线 1/3、人物下三分之一、至少一侧截断、留白 1/3、一种介质、一种光向、三级色阶配比、三个影调词、肤色隔离、一种运镜且无手持变焦、升格分级、无形容词堆砌、人物无复杂手部操作、负向词已挂。

任一项缺失先补齐再提交，不要用"绝美""震撼""顶级画质"等词代替缺失的参数。
