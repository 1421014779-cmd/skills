# prompt-writing

本文件是「国风巨物美学提示词」的可选参考：需要实际落笔撰写提示词文本时读取。做镜头规划与参数判断时不需要它。

---

## 一、五段式填空骨架

按顺序填，越靠前的部分对画面支配力越强。整条建议 120–220 字。

```
【尺度】[人物身份与数量] 位于 [巨物名称] 的 [具体部位]，
      人物仅占巨物高度的 1/[N]；[可数参照物] 提供尺度。

【构图】摄影机位于 [视高]，[平视/微微仰拍/俯拍]，
      [水线/地平线] 压在画面下三分之一；[巨物] 占据上方 [比例] 画幅，
      [哪一侧] 被画框切掉；[天空或雾] 留白约占三分之一；
      [前景虚化物] 占画幅边缘一成。

【造型】身着 [形制]，面料为 [透光纱/垂坠缎]，服色 [主色+辅色]，
      发式为 [髻型]，配 [素银细簪/白玉步摇]，持 [道具及材质]。

【光影】[顺侧光/正逆光/全向漫射]；[介质类型与浓度]；
      体积光 [是否] 穿透介质；[色温关系]。

【影调】中等偏低饱和度，[底色] 占八成、[中调] 约两成、[锚点色] 仅一处；
      暗部提亮带灰雾、高光柔和滚降、轻度高光弥散、整体柔焦降锐；
      肤色白皙透粉，与环境色保持分离。
      镜头 [缓推/横移/缓升/固定]，[升格分级说明]。
```

**负向提示词另附**，不要塞进正文。

## 二、词库

### 2.1 设色

| 层 | 词 |
|---|---|
| 底色（80%） | 青绿 `#4A6B5A`、黛青 `#2E4A5C`、天青 `#7FA3B0`、湖水蓝、苍绿、墨绿 |
| 中调（18%） | 藕荷粉 `#E8C4C8`、蜜桃粉、茱萸粉、月白 `#F2F0EA`、象牙白、浅杏 |
| 锚点（2%） | 朱砂红 `#C0392B`、绯红、正红 |

### 2.2 影调

```
中等偏低饱和度 ／ 暗部适度提亮、灰雾感、阴影层次细腻 ／ 高光柔和滚降、无死白
轻度高光弥散（Bloom）、亮部边缘乳白扩散 ／ 整体柔焦降锐、线条不生硬
画面通透纯净、无水印 ／ 肤色白皙透粉、与环境色相分离
```

### 2.3 光向与光质

```
顺侧光（给材质）／正逆光、顶逆光（给轮廓、叶脉次表面散射）／全向漫射（给氛围，无硬影）
高处漏下的光束穿透潮湿薄雾，形成暖金色斜射光柱
侧后方微弱逆光勾勒雨丝轮廓
```

### 2.4 介质

```
贴地薄雾，人物、巨物与远山分为三层，远景对比度递减
水面笼罩平流雾，两岸荷梗在雾中逐渐淡化，国画式留白
密集垂直白色雨丝，荷叶边缘垂落水帘，叶面水珠飞溅形成细微水雾
水面清澈透光，可见水下长茎与水草，涟漪打散倒影，呈现悬浮失重感
```

### 2.5 运镜

```
极慢速度向前推进 ／ 缓慢向右横移带出纵深 ／ 缓慢上升逐层揭示层叠空间 ／ 镜头固定不动
```

### 2.6 造型与道具

```
形制：唐宋风齐胸襦裙、对襟大袖衫、破裙百褶裙、披帛；高腰线垂坠长裙、宽大广袖
面料：透光真丝绡、天丝雪纺、蝉翼薄纱（高透光、有空气流动感）；哑光真丝、绉缎（光泽温润、垂坠）
纹理：素面为主，局部哑光暗纹、极细同色系丝线刺绣
发式：垂鬟分肖髻、双丫垂髫髻、朝天盘髻，发尾半披及背
饰：银质细簪、白玉小步摇、真丝发带
妆：瓷感透光底妆、柳叶远山眉、蜜桃杏粉腮唇
道具：青黄原竹钓竿＋透明细钓线；半透明白绢团扇＋竹木扇柄流苏；青瓷茶壶、粉青撇口茶盏；
      浅原木折叠茶几、编织提梁竹篮、双色细草席；粗麻绳＋原木踏板的软悬梯；
      麻绳木板秋千；原木竹架凉棚＋浅米色亚麻布帘＋彩色挂穗；粉白渐变单瓣荷花瓣舟
```

## 四、五个完整示例

### 示例 1｜巨物揭示（远景，缓推）

```
云气弥漫的水面上，一朵粉色巨型莲花破雾而出，花径直立的茎秆延伸出画面上缘。
三位身着月白与藕荷色齐胸襦裙的女子立于花瓣尖端，人物仅占巨莲高度的 1/20，
身形成为尺度参照。摄影机位于水面高度、微微仰拍，水线压在画面下三分之一处，
巨莲占据上方三分之二画幅，左右叶缘被画框切掉。贴地薄雾把人物、巨莲与远山分成三层，
远景对比度逐渐降低。顺侧柔光勾勒花瓣轮廓，花瓣半透光。
中等偏低饱和度，青绿底色配藕荷粉，暗部提亮带灰雾感，高光柔和滚降，
轻度高光弥散，整体柔焦降锐。镜头以极慢速度向前推进。
```

### 示例 2｜软梯攀爬（低机位缓升，尺度冲击最强）

```
高低错落的巨型荷叶如巨伞层叠，一片荷叶边缘垂下一架软梯：粗麻绳作侧边，
原木短棍作踏板，梯级清晰可数。两位汉服女子正沿梯级向上攀爬，一人向下递送竹篮。
梯子的每一级成为最精确的尺度参照——荷叶直径约为梯子总长的十五倍。
高处漏下的光束穿透潮湿薄雾，形成暖金色斜射光柱，将上下层荷叶切成多层空间。
摄影机位于低机位微仰，缓慢上升，逐层揭示荷叶的层叠纵深。
青绿与天青底色，月白与浅粉衣裙形成高明度焦点。暗部带灰雾、高光柔和滚降、整体柔焦。
```

### 示例 3｜花瓣舟（贴水面横移，国画留白）

```
一片粉白渐变的重瓣荷花瓣浮在雾中的水面上，宛如一叶扁舟。
船夫持青竹篙立于花瓣尾端撑船，一位身着月白襦裙的女子持半透明团扇坐在花瓣中央，
视线望向画外远方。水面笼罩平流雾，两岸密集荷梗在雾中逐渐淡化，呈国画式留白。
水面清澈透光，可见水下长茎，涟漪打散倒影，呈现悬浮失重感。
摄影机与水面近乎平齐，缓慢向右横移带出纵深，
花瓣舟占画幅近半并延伸出画面右侧边缘。
青绿底、藕荷粉主体、月白点缀，中等偏低饱和度，轻度 Bloom。
```

### 示例 4｜荷下听雨（腰高平视，情绪转折）

```
暴雨中，一位身着月白襦裙的女子静立于一片巨型荷叶下方避雨，
双手捧一只粉青撇口茶盏，抬眼望向画面外远方，身体几乎不动，手不遮挡面部。
荷叶如屋檐般覆盖画面上方，叶缘由画框切出，叶缘垂落水帘，水珠沿叶面滑落。
空气中布满密集垂直的白色雨丝，雨打荷叶飞溅形成细微水雾。
摄影机位于腰高平视，以极慢速度向前推进。
全向漫射软光，无硬阴影，侧后方微弱逆光勾勒雨丝轮廓。
青绿与黛青底色，月白为主体，低饱和，暗部提亮带湿润灰雾，整体柔焦降锐。
```

### 示例 5｜白莲回眸（平视缓推，收尾）

```
一朵巨大白色莲花的花瓣前，一位身着粉白汉服襦裙的女子侧身回眸，
手背轻贴颊侧，不遮挡面部，广袖与披帛在风中缓慢舒展。
人物占画幅高度约二分之一，巨莲花瓣作为背景从上方延伸出画框。
摄影机位于人物视线高度平视，极慢速度向前推进。
顺侧柔光，皮肤白皙透粉，与环境青绿保持色相分离。
青绿底、月白与蜜桃粉为主，低饱和，暗部灰雾、高光柔和滚降、轻度 Bloom，
肤质细腻真实，无蜡质感。
```

## 五、改造示例的规则

复用上面任一条时，只替换**业务相关的部分**：人物数量与身份、巨物种类（荷叶/莲花/茎秆/花瓣）、场景时间（日暮/晴昼/雨中）、服色与锚点位置。**不要替换**构图六参数、镜位纪律、光与介质配对逻辑、五段式顺序——那些是风格之所以成立的骨架。

替换后重新核对：倍数关系是否仍成立、参照物是否仍可数、肤色隔离是否仍写明、锚点是否仍是全片唯一。
